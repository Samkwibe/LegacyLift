def process_records( records: list, threshold: float, apply: bool ) -> tuple[float, list]: """Filter and scale records whose values exceed a threshold. Applies a fixed multiplier (MULTIPLIER = 2.5) to each record whose 'val' field exceeds the threshold. Returns the sum and the list of processed values. Args: records: List of dicts, each containing a 'val' float field. threshold: Minimum value to trigger multiplier application. apply: If False, returns (0.0, []) immediately. Returns: A tuple of (total_sum: float, processed_values: list[float]). Raises: KeyError: If any record dict is missing the 'val' key. """

README.md — Module overview
## Module Overview: legacy_processor.py Provides utilities for filtering and scaling numeric records based on a configurable threshold value. ### Main functions process_records(records, threshold, apply) Filters a list of record dicts and applies a 2.5× multiplier to values that exceed the threshold. Returns both the total sum and the processed list. ### Constants MULTIPLIER = 2.5 # Scaling factor applied to qualifying records ### Example data = [{'val': 10}, {'val': 3}, {'val': 8}] total, results = process_records(data, threshold=5.0, apply=True) # total = 45.0, results = [25.0, 3, 20.0]
